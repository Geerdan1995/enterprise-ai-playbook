# 大潮汹涌：传统制造业在AI时代的进化与重生

> **一本小说形式的企业 AI 落地手册。**
> An enterprise AI playbook, told as a novel.

这是一本用小说讲企业 AI 落地的书，面向多个岗位——财务、销售、采购、售后、车间、IT、管理层。书里没有算法推导，也没有产品选型指南。它讲的是一家工厂怎么把 AI 一件一件用起来，用的时候卡在哪儿，卡住的地方是怎么过的。

故事发生在华中一家中型齿轮箱厂「青山传动」。2026 年 3 月 17 日，陈临进厂报到，四个坏消息先到；此后一年，从旧档案数字化起步，一路用到报价、订单、售后、供应链，最后撞上这一年最大的一座山——知识图谱与本体论。全书 35 件：编者按、22 章、2 篇间章、9 个附录、后记。

## 适合谁读

- 传统行业企业里，被派去「搞 AI」的那个人——这本书陪你把一年走完
- 老板和管理层：想知道 AI 落地到底要投什么、避什么坑
- 财务、销售、采购、售后、车间、IT：每个岗位在书里都有自己的戏份
- AI 从业者：想看技术进了工厂以后，实际会发生什么
- 想看个故事的：这也是一个工厂里一群人的故事

**可能不适合**：想要算法推导或代码的（书里刻意没有，入门请走附录D）；想要产品选型指南的（同样没有——选型半年就过时，卡点十年不变）。

## 小说是虚构的，案例是真的

青山传动和书里的人物是虚构的，但他们遇到的每一件事，几乎都有真实原型。[附录C](manuscript/附录C-情节与真实案例对照表.md) 把情节和真实案例逐条对账。全书的案例原料主要来自三处，感谢他们公开这些一线材料：

- Datawhale 团队的《FDE 案例 100》案例集
- 《Enterprise AI Playbook》（Pereira、Graylin、Brynjolfsson）
- 叶小钗的企业 AI 落地公众号文章系列（[附录F](manuscript/附录F-AI用起来之后——一个实践者的方法论笔记.md) 即由这组文章整理而成，出处与改编方式在文内有完整交代）

## 这本书是怎么写出来的

这本书由作者与 AI 深度协作写成。从 v0.1 到 v4.4，每一次修订——改了什么、为什么改、原句和改句的逐字对照——都记录在 [CHANGELOG.md](CHANGELOG.md) 里，全程公开，欢迎围观。如果你关心「AI 到底能不能写长篇」，这个文件本身就是一份样本。

## 自己构建一本书

依赖：Python 3、Node.js 18+、Playwright。

```bash
git clone https://github.com/Geerdan1995/enterprise-ai-playbook.git
cd enterprise-ai-playbook
npm install
npx playwright install chromium   # PDF 导出用的浏览器内核

npm run compile    # manuscript 的 md 编译成 fragments
npm run build      # 合成整本 HTML 到 output/
npm run build:pdf  # 导出 PDF
```

Windows 用户可以直接双击 `从MD构建.bat` 一键完成以上三步。

```
manuscript/   书的正文（Markdown 源，改书改这里）
fragments/    编译中间产物（勿手改；封面/目录/封底三件手维）
assets/       插图资产（矢量原件 widgets + 书内截图 shots）
tools/        md 编译器与文风检查工具
scripts/      构建脚本（HTML/PDF 生成、插图插入、版本发布、版本真源 version.json）
output/       构建产物（不入库，从 Releases 拿成品）
```
